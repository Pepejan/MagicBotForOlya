# Бот для накладних

Надсилаєш боту `.mmo` (накладну з 1С), а він відповідає Excel-файлом, у якому зроблено те, що раніше робилося вручну:
- за основу береться файл з прайсом (`data/price-list.xlsx`) з аркушами «Прайс-лист» і «Аркуш1»;
- у «Аркуш1» з клітинки A1 вставляється весь `.mmo` у тому самому порядку, без змін в оформленні;
- у рядках товарів: **N** — термін придатності (`VLOOKUP` з прайсу), **T** — діюча ціна (`VLOOKUP`), **W** = T × P;
- товари, яких немає в прайсі (там буде `#N/A`), бот також перелічує в повідомленні.

Щоб оновити прайс, надішли боту `.xlsx` з аркушем «Прайс-лист» (колонки: Код, Назва, Ціна, Термін). Попередній прайс збережеться як `data/price-list.backup.xlsx`.

## Запуск

1. У Telegram відкрий @BotFather → `/newbot` → скопіюй токен.
2. Скопіюй `.env.example` у `.env` і встав токен у `BOT_TOKEN`.
3. Запусти бота (див. нижче).
4. Напиши боту `/start`, і він покаже твій ID. Впиши свій ID у `MY_ID`, ID сестри в `SISTER_ID`, а ID інших людей — у `EXTRA_IDS` через кому, та перезапусти бота (`docker compose up -d`), щоб ним не користувалися сторонні люди.

### Через Docker (рекомендовано)

```
docker compose up -d --build     # зібрати й запустити у фоні
docker compose logs -f           # подивитися логи
docker compose restart           # перезапустити (наприклад, після зміни .env)
docker compose down              # зупинити
```

Контейнер сам піднімається після перезавантаження комп'ютера (`restart: unless-stopped`), якщо запущений Docker.
Прайс лежить на хості в `data/` і підключений у контейнер, тож оновлення прайсу через бота не губляться.
Після зміни коду треба знову виконати `docker compose up -d --build`.

### Без Docker

```
npm install
npm start
```
Бот працює, поки відкрите це вікно.

## Перевірка без Telegram

```
npm run report -- "../накладна.mmo"
```
Готовий `.xlsx` з'явиться поруч із `.mmo`.

## Де що лежить

| Файл | Що робить |
|---|---|
| `src/bot.ts` | Telegram: приймає файли, відповідає |
| `src/mmo-parser.ts` | Розбирає `.mmo` (Windows-1251, поля через таб) |
| `src/price-list.ts` | Читає прайс з Excel |
| `src/excel-report.ts` | Заповнює «Аркуш1» даними з `.mmo` і формулами |
